# Agent instructions

## Tech Stack

- Node.js
- pnpm
- TypeScript
- Vite
- React frontend lives in `src/client`
  - Uses Mantine UI as component library: https://mantine.dev/core/package/
  - create components under `src/client/components`
- Express.js backend lives in `src/server`

## Development guide

- After making code changes run `pnpm run lint` and `pnpm run format` before committing
- After writing or editing tests run `pnpm run test`
